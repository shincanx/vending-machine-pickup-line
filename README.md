Entry for the [make.fun bounty "One Line, One Minute: The Vending Machine Pickup Line Contest"](https://make.fun/bounty/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee) — one pickup line, under 200 characters, spoken by a vending machine to a passing human.

## The entry

> I've been humming since you walked by — press B7 and I'll drop my sweetest snack. Exact change only: I can't make change for a heart like yours.

(144 characters.)

## How it works

`main.py` writes that single line to `/output/entry.txt`. No dependencies, no setup — run it with Python 3:

```sh
python3 main.py
```

The output is deterministic: repeated runs produce byte-identical output.
